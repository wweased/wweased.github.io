DriveBeat.

Музыка, которая звучит внутри автомобиля — а не поверх игры.

Интеграция музыки из медиасессии Windows в BeamNG.drive. Звук воспроизводится через виртуальные динамики машины; открытые двери влияют на его восприятие.

Этот проект — личная разработка. Ниже описаны его задачи, реализация и известные ограничения.

Тип

Модификация для BeamNG.drive

Технологии

BeamNG.drive / Lua / JavaScript / JBeam / Windows audio

Состояние

Личный проект · 2026

Зачем я это сделал

Обычный музыкальный плеер играет поверх игры и не учитывает окружение. Мне хотелось, чтобы музыка ощущалась частью салона.

Как устроено

Система связывает Windows-компаньон с игровым модом: медиасессии, Lua-логика, UI на JavaScript и пространственное воспроизведение в машине.

Возможности

  • Четыре дверных динамика и сабвуфер
  • Изменение звучания при открытии дверей
  • Музыка из Spotify, браузера и других источников Windows
  • Внутриигровой интерфейс телефона

Что ещё улучшить

В версии 0.4.0 остановка воспроизведения через программу-компаньон иногда срабатывает некорректно.
