DiscordMedia.

Что играет на компьютере — отображается в Discord.

Программа на C# и WPF считывает активную медиасессию Windows и обновляет Discord Rich Presence.

Этот проект — личная разработка. Ниже описаны его задачи, реализация и известные ограничения.

Зачем я это сделал

Музыка из разных приложений не всегда отображается в статусе Discord единообразно.

Как устроено

Использовал системные медиасессии Windows и Discord RPC для отображения информации о текущем воспроизведении.

Возможности

  • Чтение Windows Media Sessions
  • Отображение трека в Discord Rich Presence
  • WPF-интерфейс
  • Работа с медиаданными разных приложений

Что ещё улучшить

Публичный репозиторий содержит исходники, но также служебные файлы сборки; документация нуждается в обновлении.
