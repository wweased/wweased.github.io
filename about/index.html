Сначала задача.
Потом код.

Я разрабатываю небольшие Windows-приложения и модификации игр. Меня интересуют задачи, где результат можно запустить и проверить.

Как я работаю

Использую ИИ для ускорения разработки, разбираюсь в логике, вношу правки и тестирую программы. Не выдаю автоматически сгенерированный код за результат многолетней коммерческой разработки.

Что использую

  • C# и WPF — интерфейсы Windows
  • .NET — небольшие утилиты и автоматизация
  • Lua, JavaScript и JBeam — игровые интеграции
  • Java и Gradle — Minecraft-моды
  • Windows Media API, Discord RPC и Whisper

Какие задачи интересны

Небольшие приложения, обработка файлов, автоматизация повторяющихся действий, интерфейсы и интеграции. Предпочитаю задачи с понятным объёмом и конкретным результатом.
